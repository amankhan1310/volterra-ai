# backend

FastAPI service for VOLTERRA AI: REST API (`/api/v1`), SQLAlchemy models, Alembic migrations,
analytics services and the background job worker.

**Status:** empty scaffold (Phase 0). The analytics port starts in Phase 2 and the database/API
in Phase 3 — see [`../ARCHITECTURE_PLAN.md`](../ARCHITECTURE_PLAN.md) §7 for the planned
layout (`app/api`, `app/services`, `app/analytics`, `app/db`, `app/worker`, `alembic/`).
