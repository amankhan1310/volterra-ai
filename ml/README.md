# ml

The `volterra_ml` package: dataset loaders (NASA PCoE, CALCE, Severson, synthetic), validation
schemas, feature engineering, models, anomaly detectors, simulator calibration and evaluation.

**Status:** empty scaffold (Phase 0). Implementation starts in Phase 6–7 — see
[`../ARCHITECTURE_PLAN.md`](../ARCHITECTURE_PLAN.md) §9. Datasets and trained models are never
committed; they live in the git-ignored `data/` and `artifacts/` folders.
